# 通知中心图标规格

## 标记已读图标

当前通知列表的“标记已读”使用纯图标按钮，不显示文字按钮。

| 规格 | 文件 | 使用场景 | 画布 | 线宽 |
|---|---|---|---:|---:|
| Compact | `mark-read-16.svg` | 紧凑列表、托盘菜单 | 16 px | 1.5 px |
| Default | `mark-read-20.svg` | 通知列表操作按钮 | 20 px | 1.75 px |
| Toolbar | `mark-read-24.svg` | 页面工具栏 | 24 px | 2 px |
| Large | `mark-read-32.svg` | 空状态、确认区域 | 32 px | 2.25 px |

统一规则：

- 使用 `viewBox="0 0 24 24"`，保持不同尺寸的几何比例一致；
- 图标为无填充圆角勾线，默认颜色 `#1769D1`；
- Hover 背景使用 `#EAF2FF`，禁用状态由控件降低透明度；
- 图标按钮保持正方形、内容居中，不使用文字替代；
- 当前 Avalonia 控件使用同一几何形状的运行时勾号，SVG 文件作为设计资产和后续 SVG 渲染入口。
