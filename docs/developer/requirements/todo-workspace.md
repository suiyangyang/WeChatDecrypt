# Todo 工作区要求

## 任务管理

Todo 工作区同时承担任务执行和日报整理两个职责：任务看板用于状态跟踪，随手记和日报区域用于快速输入、解析、工时登记和日报上传。

任务至少支持以下字段：

- 标题、描述、项目和备注；
- 工作日期、截止日期、状态和优先级；
- 标签、Checklist、归档状态；标签支持常用颜色选择，默认黑底白字，卡片按标签颜色分别展示；卡片更多菜单固定在卡片右上角，不与标题同行排列；
- 重复规则和截止日期前的提醒分钟数；
- 随手记来源文本与排序值。

状态固定为 `NotStarted`、`InProgress`、`Blocked`、`Completed`。看板按状态分列，归档任务默认不显示。默认工作看板包含“待确认”“待办”“进行中”“已完成”四个系统列表；“待确认”列表不可删除、不可修改名称。

## 筛选与统计

看板支持关键词、状态、优先级和日期范围组合筛选。日期范围包括全部、今天、即将到期和已逾期。统计摘要至少包含活动任务数、已完成数、逾期数和登记工时。

## 持久化

Todo 数据与联系人域共享 SQLite 数据库。新增字段必须通过 schema migration 加入；旧数据库读取时使用字段默认值，不得破坏现有随手记、日报和 Excel/JSON 交换数据。

当前数据库 schema 版本为 10。
