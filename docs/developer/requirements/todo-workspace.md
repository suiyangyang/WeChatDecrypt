# Todo 工作区要求

## 任务管理

Todo 工作区同时承担任务执行和日报整理两个职责：任务看板用于状态跟踪，随手记和日报区域用于快速输入、解析、工时登记和日报上传。

任务至少支持以下字段：

- 标题、描述、项目和备注；
- 工作日期、截止日期、状态和优先级；截止日期信息块按本地日期自动显示颜色：当天为绿色、本周内后续日期为橙色、已过期为红色；
- 标签、Checklist、相关文件/文件夹、归档状态；标签支持最多 10 个，每个标签最多 30 个字符；编辑区以流式排列标签，标签文字按所选颜色显示且无背景填充，悬停标签时显示删除按钮，所有标签共用一套颜色选择控件，选中的颜色圆圈显示黑色边框，卡片按标签颜色分别展示；悬停卡片 Checklist 摘要标签时，通过定制 ToolTip 按序号逐项展示清单内容，并以 `√` 和 `⭕` 标识完成与未完成状态；卡片支持双击打开编辑页面，更多菜单无论是否有标签都固定在卡片右上角并保持与边缘的固定间距，有标签时标题位于标签下方，无标签时标题从卡片顶部开始显示，并提供移动到列表顶端；相关文件/文件夹保存本地路径，编辑页支持分别选择文件或文件夹，文件路径在空间足够时优先完整显示，仅在可用宽度不足时按界面宽度省略，并调用系统打开；链接支持左键直接打开，右键选择“打开文件”或“在资源管理器打开”；卡片支持右键弹出与“更多”菜单一致的操作菜单，操作含编辑详情、移入已完成（仅待办/进行中状态的卡片可见，点击后卡片移入“已完成”列表）、移动到顶端、添加引用（子菜单添加文件/添加文件夹，点击后直接打开系统文件/文件夹选择器并保存本地路径）、复制为文本（将标题与描述按“标题换行描述”格式复制到剪贴板）、归档/恢复和删除；
- 重复规则和截止日期前的提醒分钟数；
- 随手记来源文本与排序值。

状态固定为 `NotStarted`、`InProgress`、`Blocked`、`Completed`。看板按状态分列，归档任务默认不显示。默认工作看板包含“待确认”“待办”“进行中”“已完成”四个系统列表；看板和列表区域随窗口高度伸缩，任务内容超出可视区域时提供滚动；“待确认”列表不可删除、不可修改名称。

已归档卡片支持自动清理：默认启用，归档保留天数默认 180 天，可在桌面“设置-工作设置”关闭或调整为 1–3650 天。清理按卡片归档时间起算，只永久删除已归档且超过保留天数的卡片，归档列表中的未归档卡片不在清理范围内；同一设置分区还提供立即清理入口和当前归档统计。

桌面 TODO 看板中，每个列表首屏只加载前 50 张卡片（不足 50 张时全部加载），滚动接近列底部（剩余不足 120 px）时按 50 张一批继续加载，直到全部显示；首屏不足一视口高时自动续批填满。列表头部计数始终显示该列表全部卡片数。切换筛选、排序、搜索或公司条件后列表整体重建，加载进度重置为首批。

## 筛选与统计

看板支持关键词、状态、优先级和日期范围组合筛选。日期范围包括全部、今天、即将到期和已逾期；逾期仅统计未完成且未归档的任务。桌面工作看板的筛选菜单另外支持按完成日期起止范围筛选已完成卡片；已完成卡片在底部信息块中以绿色标签显示完成日期。截止日期信息块按本地日期显示当天绿色、本周内后续日期橙色、已过期红色。卡片右键菜单中的归档/恢复支持 `Ctrl+Shift+A`，删除支持 `Delete`。统计摘要至少包含活动任务数、已完成数、逾期数和登记工时。

日报上传的默认时间范围为当前工作日期所在周的上一自然周，从周一开始，到周日结束。用户可在上传确认窗口中修改起止日期。

## 持久化

Todo 数据与联系人域共享 SQLite 数据库。新增字段必须通过 schema migration 加入；旧数据库读取时使用字段默认值，不得破坏现有随手记、日报和 Excel/JSON 交换数据。

当前数据库 schema 版本为 11。
