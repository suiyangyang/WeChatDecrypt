# App 入口

Fairy 主窗口左侧直接提供“联系人管理”导航。进入后，原联系人管理应用的“主页、联系人、公司、项目、微信联系人、导入导出”继续以内部 Tab 展示。

“App”页面保留应用快捷入口：

- 点击“联系人管理”图标，切换到主窗口的联系人管理页面；
- 点击“Todo / 日报”图标，打开独立的 Todo / 日报应用。

应用卡片从工作区左上角开始排列。右键单击系统托盘中的 Fairy 图标，在“更多App”子菜单中也可以打开联系人管理页面或启动 Todo / 日报。

联系人管理页面与微信分析使用同一进程内服务和同一个联系人域 SQLite 数据库；独立启动联系人管理应用仍可作为兼容入口使用。
