# TodoList 使用说明

## 任务看板

在“格式化结果”视图中，Todo 会按“未开始、进行中、阻塞、已完成”分列展示。桌面主窗口的 TODO 页面会按列表横向展示任务，默认包含“待确认”“待办”“进行中”“已完成”四个列表；看板和列表区域会随窗口高度变化，内容超出可视区域时可滚动查看；“待确认”列表不可修改名称或删除。微信解析识别出的新工作内容会先进入“待确认”列表。

卡片较多的列表默认只显示前 50 张，向下滚动接近列底部时会自动加载后续卡片；列表上方显示的卡片数量始终是全部卡片的总数。

- 点击“＋ 新建 Todo”创建空白任务。
- 点击“日报模板”或“客户模板”快速创建常用任务。
- 点击看板列表底部的“添加卡片”打开空白任务编辑器；保存后卡片会加入当前列表。
- 使用卡片上的状态选择器切换任务状态；桌面 TODO 卡片支持双击打开编辑页面，右上角“更多”菜单可编辑详情、移动到列表顶端、归档或删除；卡片还支持右键弹出同样的操作菜单，可编辑详情、移入已完成、移动到列表顶端、添加文件/文件夹引用、复制为文本、归档或删除。
- 使用“完成”“归档”“删除”管理任务。
- 使用上下箭头或直接拖拽卡片调整任务顺序；拖到目标卡片上半区插入其前方，下半区插入其后方，拖到列表空白处追加到末尾。

## 搜索和筛选

看板上方的搜索框可以查找任务标题、项目、描述、备注、来源和标签。还可以组合筛选状态、优先级和日期范围：全部、今天、即将到期、已逾期；“已逾期”仅包含未完成且未归档的任务。桌面主窗口 TODO 页的状态、公司和完成日期范围筛选收纳在右上角居中的漏斗形“筛选”图标按钮中；排序方式收纳在筛选按钮左侧的排序图标按钮中，点击后弹出排序子菜单，可选“手动顺序”“按优先级”“按截止时间”“按创建时间”“按完成时间”，当前选项带勾选标记；子菜单旁另有方向图标按钮，点击切换升序/降序，图标随当前方向显示上箭头或下箭头，排序为“手动顺序”时该按钮不可用。完成日期可分别设置“从”和“至”，只匹配已完成且完成时间落在范围内的卡片；清空两个日期即可取消此条件。公司筛选支持输入公司名称或完整拼音后选择匹配项。截止日期信息块会按本地日期自动着色：当天为绿色，本周内后续日期为橙色，已过期为红色；未设置截止日期时保持默认颜色。

卡片左上角按独立色块显示自定义标签，标签文字统一为白色；无论是否有标签，卡片右上角都固定显示“更多”菜单按钮并保持与边缘的固定间距；有标签时标题从标签下方开始显示，无标签时标题直接从卡片顶部开始显示；描述下方显示相关文件或文件夹链接，底部以蓝色圆角信息块显示截止日期、Checklist 进度、优先级和公司；截止日期信息块会按本地日期自动着色：当天为绿色，本周内后续日期为橙色，已过期为红色；已完成卡片还会在同一区域以绿色标签显示完成日期；信息块会随卡片宽度自动换行。任务详情中可以继续补充描述、项目、负责人、优先级、截止日期、标签、Checklist、相关文件、备注和提醒设置；鼠标悬停卡片底部的 Checklist 标签时，会通过定制 ToolTip 按序号展示清单内容，并用 `√`/`⭕` 标识完成状态。点击“添加文件”或“添加文件夹”选择引用项，保存后会在卡片描述下显示可点击链接；文件路径会优先完整显示，只有在可用宽度不足时才按界面宽度省略，鼠标悬停可查看完整路径，左键可直接打开，右键可选择“打开文件”或“在资源管理器打开”。添加或编辑标签时，最多添加 10 个标签，每个标签最多 30 个字符；标签在编辑区域中以彩色文字显示，没有背景色块，并自动向右流式排布，一行放不下时换行；鼠标悬停标签时，标签右侧显示删除按钮；所有标签共用一套颜色选择控件，先选择标签再选择颜色，选中的颜色圆圈显示黑色边框。所属公司支持输入公司名称或拼音筛选后选择，下拉选择框会与同列输入框保持一致宽度。编辑窗口正文默认使用 12 号字，截止日期使用日期控件，单行输入框、下拉框和日期选择器采用紧凑高度，保存操作固定在底部。

## 随手记与日报

原始随手记、结构化结果、左右对照和日报浏览仍然保留。编辑 Todo 后，点击顶部保存按钮或使用 `Ctrl+S` 保存到本地数据；取消或直接关闭编辑窗口不会刷新看板数据，保存后看板横向滚动位置保持不变。

卡片右键菜单中的归档/恢复支持 `Ctrl+Shift+A`，删除支持 `Delete`。上传日报时，时间范围默认选择当前工作日期所在周的上一自然周，即上周一至上周日；仍可在上传前手动调整起止日期。

## 数据安全

Todo 与日报保存在本机 SQLite 数据库中。来自微信随手记的来源文本只在本地工作区中展示和保存。
