# TodoList 使用说明

## 任务看板

在“格式化结果”视图中，Todo 会按“未开始、进行中、阻塞、已完成”分列展示。桌面主窗口的 TODO 页面会按列表横向展示任务，默认包含“待确认”“待办”“进行中”“已完成”四个列表；“待确认”列表不可修改名称或删除。微信解析识别出的新工作内容会先进入“待确认”列表。

- 点击“＋ 新建 Todo”创建空白任务。
- 点击“日报模板”或“客户模板”快速创建常用任务。
- 使用卡片上的状态选择器切换任务状态；桌面 TODO 卡片中，状态右侧会显示优先级和“更多”菜单，编辑详情请从“更多”菜单进入。
- 使用“完成”“归档”“删除”管理任务。
- 使用上下箭头或直接拖拽卡片调整任务顺序；拖到目标卡片上半区插入其前方，下半区插入其后方，拖到列表空白处追加到末尾。

## 搜索和筛选

看板上方的搜索框可以查找任务标题、项目、描述、备注、来源和标签。还可以组合筛选状态、优先级和日期范围：全部、今天、即将到期、已逾期。桌面主窗口 TODO 页的状态和公司筛选收纳在右上角“筛选”图标按钮中，排序方式单独显示。公司筛选支持输入公司名称或完整拼音后选择匹配项。

卡片左上角按独立色块显示自定义标签，标签文字统一为白色；卡片右上角固定显示“更多”菜单按钮，不与标题同行对齐；中间显示标题和描述，底部以蓝色圆角信息块显示截止日期、Checklist 进度、优先级和公司；信息块会随卡片宽度自动换行。任务详情中可以继续补充描述、项目、负责人、优先级、截止日期、标签、Checklist、备注和提醒设置。添加或编辑标签时，可以从黑、红、橙、黄、绿、蓝、紫、灰等常用颜色中选择，默认使用黑底白字；所属公司支持输入公司名称或拼音筛选后选择，下拉选择框会与同列输入框保持一致宽度。编辑窗口正文默认使用 12 号字，截止日期使用日期控件，标签以轻量胶囊样式展示，单行输入框、下拉框和日期选择器采用紧凑高度，保存操作固定在底部。

## 随手记与日报

原始随手记、结构化结果、左右对照和日报浏览仍然保留。编辑 Todo 后，点击顶部保存按钮或使用 `Ctrl+S` 保存到本地数据；取消或直接关闭编辑窗口不会刷新看板数据，保存后看板横向滚动位置保持不变。

## 数据安全

Todo 与日报保存在本机 SQLite 数据库中。来自微信随手记的来源文本只在本地工作区中展示和保存。
