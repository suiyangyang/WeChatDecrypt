# Fairy 设置

在主页面左侧打开“设置”后，设置页面会覆盖主页面，并显示独立的左侧菜单。点击左上角“返回主页面”可回到进入设置前的页面。主导航不再提供“关于”入口。

设置菜单分为：

- “常规”：启动设置、时间设置；
- “工作设置”：归档任务自动清理；
- “微信分析”：微信数据访问授权、QwenPaw 登录、微信分析设置；
- “通知”：通知设置、第三方通知接口。

QwenPaw 登录密码和第三方通知 Bearer Token 默认隐藏。两个敏感字段的显示/隐藏按钮都位于输入框右侧内部，点击后可切换明文与隐藏状态。

## 微信数据访问授权

“设置 > 微信分析”顶部显示“微信数据访问授权”卡片。首次使用时，保持需要分析的微信账号在本机登录，点击“打开微信数据工具”，依次完成微信检测、获取数据库密钥和数据库解密，然后返回 Fairy 点击“重新检测”。Fairy 只检查密钥文件和解析服务是否可用，不显示数据库密钥内容。

卡片会显示当前微信数据根目录。数据根目录中应包含 `output/account_keys.json`；如数据保存在其他位置，可点击“选择数据目录”。直接选择 `output` 时，Fairy 会自动改用其上一级目录。目录修改会保存在本机，完全退出 Fairy（包括系统托盘实例）并重新启动后生效。

状态为“目录不一致”表示 `10492` 端口上的微信解析服务使用了其他数据目录。此时应选择与现有服务一致的数据目录，或先退出旧的微信数据工具，再重新检测。

若微信增量分析通知提示后端未完成初始化，可能是后端未在 60 秒内加载账号或日志目录与当前数据目录不一致，并不一定表示密钥文件缺失。请先核对卡片中的数据目录和授权状态，再查看该目录 `output` 下的后端日志。

## QwenPaw 登录

成功登录一次后，Fairy 会在本机记住服务器地址、用户名、密码和分析 Agent。下一次打开客户端时会自动用这些信息登录 QwenPaw，并沿用上次的分析 Agent 继续自动分析，无需重新填写；设置页会显示“已自动登录 QwenPaw…”，密码框里记住的密码默认仍是隐藏状态。

自动登录失败时（例如 QwenPaw 换了地址、密码被修改），登录框会保留上次记住的服务器地址和用户名，改成正确信息后重新点击“登录并读取 Agent”即可，新的登录信息会覆盖旧的。这些信息只保存在当前 Windows 用户本机的加密文件中，换电脑或换 Windows 账号需要重新登录。

## 开机启动

勾选“开机启动 Fairy”后，Fairy 会加入当前 Windows 用户的启动项，并在设置区域显示成功提示。关闭选项后会移除该启动项。

## 归档任务自动清理

“工作设置”管理已归档任务的清理规则，默认开启自动清理，归档保留天数为 180 天。

- 清理按任务被归档的时间起算，只永久删除归档时长超过保留天数的已归档任务卡片，删除后不可恢复；未归档任务不受影响，归档列表中的未归档卡片也不会被删除。
- Fairy 启动后约 20 秒执行第一次检查，之后每 6 小时检查一次；应用未运行期间不会执行清理。
- 每次自动清理后，通知中心会收到一条“已自动清理归档任务”通知，工作页同步刷新。
- “立即清理过期归档”按当前保留天数马上执行一次，不受自动清理开关限制。
- 保留天数支持 1–3650 天。点击“保存工作设置”后立即生效并保存在本机，下次启动继续生效。

## 外部通知接入

“通知”中的“第三方通知接口”区域会显示接口地址和 Bearer Token。Token 默认以密码样式隐藏，点击输入框内右侧的眼睛按钮可以立即显示或隐藏；显示的 Bearer Token 就是接口实际使用的认证凭据，外部程序应将其放入 `Authorization: Bearer <token>` 请求头。如果外部程序运行在另一台电脑上，请按[第三方通知 HTTP 接口开发文档](../developer/operations/third-party-notification-api.md)完成网络访问配置。

“微信分析设置”的白名单使用等高的联系人、公司双栏选择区。两栏内容分别在栏内滚动，不会因一侧项目较多而拉伸另一侧布局。

## 微信分析通知

“通知设置”提供两项可独立勾选的完成通知策略：

- “每次分析通知”默认开启，每次成功分析都生成完成通知；
- “有工作内容时发送通知”在发现 TODO 候选或待确认问题时生成完成通知。

工作候选和待确认问题本身始终保留可操作通知，不受完成通知策略影响。两项设置会保存在本机，下次启动时继续生效。
