# 微信分析设置

在“设置”页面的“微信分析设置”中，可以选择分析 Agent，配置自动分析范围、解析间隔和分析内容。微信分析执行页只负责发起分析。

## 首次准备

首次分析前，请先保持当前微信账号在本机登录，打开配套的微信数据工具完成微信检测、数据库密钥获取和数据库解密，再重新启动 Fairy。若数据尚未准备好，微信分析通知会显示具体缺少的文件和后续处理步骤。

## 分析 Agent

登录 QwenPaw 后，在“微信分析设置”中选择要执行分析的 Agent。微信分析默认优先使用 `WeChatAnalysist`；选择结果会保存，程序重启后继续使用。手动分析和自动分析都会使用当前选择的 Agent。

## 白名单

开启“启用白名单”后，只分析白名单中的联系人和公司相关会话；关闭后分析所有联系人和群聊。白名单支持从联系人和公司列表中多选，群聊名称包含所选联系人或公司名称时也会纳入分析。

联系人管理中的联系人可以维护一个或多个微信 ID。配置微信 ID 后，分析会优先按微信 ID 精确匹配；没有微信 ID 时才使用姓名、昵称、公司、项目和群聊名称匹配。联系人或公司资料修改后，下一次手动分析或自动分析轮询会自动重新读取最新数据。

分析前，程序会使用本地维护的联系人、公司和项目资料为当前会话补充业务上下文，帮助 QwenPaw 正确理解客户和项目。只发送必要的名称和项目标签，不会把联系人数据库文件复制到 QwenPaw，也不会把电话、邮箱和备注作为分析上下文发送。无法唯一匹配时，程序不会根据名称猜测归属。

如需让 QwenPaw 通过 MCP 查询这部分本地业务上下文，请参阅[《QwenPaw 微信分析 MCP 配置说明》](qwenpaw-wechat-context-mcp.md)。

联系人和公司白名单分别限制在固定高度区域内，列表过长时可在各自区域中滚动查看。

## 微信联系人与群聊归属

主 App 的“联系人管理 > 微信联系人”页可以从本机微信解析结果同步所有可显示的联系人和群聊。同步只读取联系人名称、类型和最近沟通时间，不保存聊天正文。

列表中的类型为“联系人”或“群聊”。群名称优先采用微信联系人元数据；微信仅返回 `数字@chatroom` 等内部标识时显示为“未知群聊”。最近沟通时间支持微信解析服务返回的本地化时间格式。

微信联系人列表支持高级筛选：可以按公司归属筛选“已分配”“未分配”或“全部”，也可以按联系人类型筛选“群聊”“联系人”或“全部类型”。两组条件可以组合使用，并可继续输入名称、账号或公司关键字进行搜索。

每次刷新都会按当前微信目录对账；已不再出现在微信中的旧记录不会继续显示，但已有的公司归属仍会保留。

首次同步后，可以为每个联系人或群聊选择所属公司并点击保存图标；也可以点击“全部保存”，一次保存当前列表中所有已修改但尚未保存的公司归属。保存后重新打开联系人管理，所属公司仍会保留。联系人、项目和微信联系人的公司选择框支持直接输入中文或公司名称完整拼音序列筛选，不使用首字母或相似匹配。微信联系人的公司选择框在输入时自动展开候选，清空搜索文字可查看全部公司；仅输入搜索文字不会清除已有归属，需要取消归属时请选择“未分配”并保存。点击“自动分配公司”可按联系人或群聊名称严格匹配公司中文名称或完整拼音序列，字符/拼音必须按原顺序连续出现，不接受相似或缺字匹配；联系人名称和公司名称任一方包含另一方时即可命中。该操作只处理活跃且尚未分配公司的条目，不会覆盖已有归属。分析生成的 TODO 会自动带上该公司名称；微信联系人名称变化时，系统按“微信账号 + 联系人标识”保留原有公司归属。未配置公司时，TODO 不会自动猜测公司。

## 工作页

“工作”页分为“TODO”和“工作通知”两个 Tab。TODO Tab 使用 Trello 风格看板，占满工作区域：默认按“待确认”“待办”“进行中”“已完成”列表展示卡片，也支持创建自定义列表；微信分析识别出的新工作内容会先进入“待确认”列表，确认后转入“待办”列表。默认显示全部未归档卡片并按手动顺序排列，同时提供搜索；状态和公司筛选收纳在右上角“筛选”图标按钮中，排序方式可单独选择手动顺序、优先级、截止时间或创建时间。公司筛选支持输入公司名称或完整拼音后选择匹配项。只有在“手动顺序”且未启用筛选时，卡片才支持拖拽到其他列表或在列表内调整顺序；拖动到目标列表的整个面板区域都可以放置，空列表也可以直接接收卡片。点击卡片可编辑标题、摘要、High/Medium/Low 优先级、负责人、截止时间、所属列表、所属公司、标签、Checklist、评论和归档状态。卡片悬浮时的更多菜单支持编辑详情、归档/恢复和删除，删除前需要确认。列表左侧的竖向三点手柄可拖动调整列表位置；自定义列表标题通过更多菜单重命名并在失去焦点时保存，“待确认”列表不可修改名称、不可删除或归档；其他系统列表不可删除或归档；自定义列表更多菜单支持归档、恢复和删除，删除列表及其中卡片前需要确认。归档列表及其中卡片可在“已归档”筛选中查看并恢复。公司选项直接读取联系人管理中的启用公司。数据保存于本地 TODO 数据库，应用重启后仍保留看板结构和卡片内容。

TODO 卡片的详情弹窗中，标签和 Checklist 支持新增、编辑或删除，评论支持新增并随卡片持久化；Checklist 的勾选状态会显示在卡片摘要上。工作通知仍位于独立 Tab，仅显示未读工作通知或仍需操作的通知，完整历史请到“通知中心”查看。

## 分析内容


可以多选以下内容：

- ToDo
- 客户提问：客户 `@我` 提出问题，且我在 10 分钟内没有回复。

## 自动分析模式

支持以下消息范围：

- 1 个月内的消息（默认）
- 本周的消息
- 最近 50 条
- 未分析过的消息

每个联系人或群聊都会记录最后成功分析到的消息位置。每一轮分析会为 QwenPaw 创建一个“聊天记录分析_yyyyMMdd_HHmm”会话，并在该轮内按顺序处理有新增消息的联系人；没有新增消息的联系人不会发送。选择“未分析过的消息”时，首次发现会话不会自动回溯历史；每轮最多读取最近 200 条，超出这 200 条的更早消息本轮不处理，也不会自动补处理。其他时间范围模式首次按设置范围分析，后续也只处理游标之后的新消息。

“分析最近会话”会先在本地按白名单和分析范围筛选有待分析消息的联系人；没有新增消息的联系人不会发送给 QwenPaw。本轮使用一个分析会话，按联系人顺序逐个等待返回。页面会显示本轮联系人总数、消息总数和当前处理联系人。

## 设置最新分析点

当联系人或群聊中已有大量历史消息时，可以在“微信分析”页点击“设置最新分析点”。系统会按当前分析范围读取每个联系人和群聊的最新消息，并将其设为已分析位置，不会提交给 QwenPaw 分析。之后选择“未分析过的消息”时，只处理该位置之后的新消息。自动分析成功后，会自动把本次分析到的最新消息更新为新的分析点。

## 解析间隔

“解析间隔（min）”控制自动分析轮询的频率，单位为分钟，默认 5 分钟，最小 1 分钟。保存设置后，从下一次自动轮询开始生效；手动点击“分析最近会话”不受此间隔限制。

QwenPaw 分析使用流式响应：首个有效内容等待 2 分钟，连续 1 分钟没有新数据，或单个联系人分析超过 10 分钟时，本次联系人分析会失败；失败不会推进该联系人的分析位置。
