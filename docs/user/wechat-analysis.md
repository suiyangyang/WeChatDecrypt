# 微信分析设置

在“设置”页面的“微信分析设置”中，可以选择分析 Agent，配置自动分析范围、解析间隔和分析内容。微信分析执行页只负责发起分析。

## 首次准备

首次分析前，请先保持当前微信账号在本机登录，打开配套的微信数据工具完成微信检测、数据库密钥获取和数据库解密，再重新启动 Fairy。若数据尚未准备好，微信分析通知会显示具体缺少的文件和后续处理步骤。

## 分析 Agent

登录 QwenPaw 后，在“微信分析设置”中选择要执行分析的 Agent。手动分析和自动分析都会使用当前选择的 Agent。

## 白名单

开启“启用白名单”后，只分析白名单中的联系人和公司相关会话；关闭后分析所有联系人和群聊。白名单支持从联系人和公司列表中多选，群聊名称包含所选联系人或公司名称时也会纳入分析。

联系人管理中的联系人可以维护一个或多个微信 ID。配置微信 ID 后，分析会优先按微信 ID 精确匹配；没有微信 ID 时才使用姓名、昵称、公司、项目和群聊名称匹配。联系人或公司资料修改后，下一次手动分析或自动分析轮询会自动重新读取最新数据。

联系人和公司白名单分别限制在固定高度区域内，列表过长时可在各自区域中滚动查看。

## 微信群聊与公司归属

主 App 的“联系人管理 > 微信群聊”页可以按最近 1～365 天从本机微信解析结果同步有沟通的群聊。同步只读取账号、群聊标识、群名称和最后沟通时间，不保存聊天正文。

群名称优先采用微信联系人元数据；微信仅返回 `数字@chatroom` 等内部标识时显示为“未知群聊”，内部标识仍会显示在“账号 / 标识”列。最近沟通时间支持微信解析服务返回的本地化时间格式。

首次同步后，可以为每个群聊选择所属公司并保存。分析生成的 TODO 会自动带上该公司名称；群聊名称变化时，系统按“微信账号 + 群聊标识”保留原有公司归属。未配置公司时，TODO 不会自动猜测公司。

## 分析内容

可以多选以下内容：

- ToDo
- 客户提问：客户 `@我` 提出问题，且我在 10 分钟内没有回复。

## 自动分析模式

支持以下消息范围：

- 1 个月内的消息（默认）
- 本周的消息
- 最近 50 条
- 未分析过的消息

“未分析过的消息”会按每个联系人或群聊分别记录最后分析到的消息，只分析其后的新消息；首次发现会话时不会自动回溯历史。

## 设置最新分析点

当联系人或群聊中已有大量历史消息时，可以在“微信分析”页点击“设置最新分析点”。系统会按当前分析范围读取每个联系人和群聊的最新消息，并将其设为已分析位置，不会提交给 QwenPaw 分析。之后选择“未分析过的消息”时，只处理该位置之后的新消息。自动分析成功后，会自动把本次分析到的最新消息更新为新的分析点。

## 解析间隔

“解析间隔（min）”控制自动分析轮询的频率，单位为分钟，默认 5 分钟，最小 1 分钟。保存设置后，从下一次自动轮询开始生效；手动点击“分析最近会话”不受此间隔限制。
